# UIWarden 功能使用指南

## 配置中心

首次使用先配置执行底座和模型。UIWarden 负责把任务、工具协议和证据交给所选底座；账号认证、模型权限和额度由底座自身管理。切换底座或模型只影响新任务，运行中的任务不会热切换。

浏览器、系统权限和环境变量配置也集中在配置中心。连接测试只验证配置与最小调用，不代表模型一定具备视觉能力或目标站点权限。

## UI 操作

UI 操作是通用 Agent 工作区。每个会话固定一种执行目标，支持停止、执行观察、产物查看和诊断导出。

### 浏览器

| 模式 | 适合 | 注意事项 |
| --- | --- | --- |
| Playwright 配套 Chromium | 隔离、可复现的默认浏览器任务 | 使用独立 Profile，不继承用户日常浏览器登录态 |
| UIWarden 内置浏览器 | 客户端内可视、可人工接管的任务 | 仅桌面客户端可用 |
| 用户浏览器桥接 | 在用户浏览器中新建受控标签或标签组 | 需要安装并配对随包 Bridge 扩展；不要接管未授权页面 |
| 外部 CDP | 调试已显式开启远程调试的 Chromium 浏览器 | 只连接本机 HTTP CDP 地址，并锁定目标 target |

任务执行期间可查看活动步骤、页面截图、标签关系、网络/控制台信息和 Browser Rep。涉及登录、支付、发布或删除等高风险最终动作时，应保留人工确认。

### 电脑桌面

Computer Runtime 通过平台 Provider 观察应用、AX Tree、窗口截图并执行原子动作。Agent 应先发现并绑定应用，再基于新快照操作；没有界面证据时不能把常识推断当成执行成功。

- macOS 使用 Accessibility Provider，并按需使用屏幕录制。
- Mock Provider 用于协议和 Docker 验证，不代表真实桌面操作成功。
- Windows Provider 只有在对应发行包和系统验收完成后才应启用。
- “后台执行”要求目标应用支持无干扰动作；不支持时会停止，不应静默降级到抢占前台。

### 画中画与人工接管

画中画是执行画面的只读或受控预览，不等同于独立虚拟桌面。浏览器内核可提供隔离页面；原生桌面任务仍可能操作真实应用、改变焦点或与用户输入冲突。执行关键桌面任务时不要同时操作同一应用。

需要人工处理验证码、登录或页面歧义时，暂停 Agent、完成操作后再继续；继续后 Agent 必须重新观察页面，不能沿用旧快照。

## 测试、巡检与回归

- **测试任务**：面向一次 UI 测试执行，保留步骤、断言和产物。
- **巡检任务**：按任务定义重复检查页面或流程。
- **回归任务**：按用例集合运行并汇总结果。

这些模块可使用专用测试 Skill；不要与 UI 操作中的 Browser/Computer 原子 Skill 混用。长任务应配置合理超时，并通过停止按钮结束失控执行。

## 评测实验室

评测集只描述 Case、输入、标签和断言；评测方案再绑定执行目标、底座、模型、运行参数和 LLM 评审配置。建议优先使用可复现 Fixture，依赖真实账号或本地办公环境的 Case 必须显式标记。

结果中心提供单例重跑、继续未执行、完整重跑、耗时、Token、Oracle、LLM 评审和诊断导出。Oracle 与 LLM 评审是独立指标：确定性状态优先由 Oracle 判定，LLM 用于评价完成度和证据质量，不能替代缺失的执行证据。

## 产物与隐私

Browser Rep、Native Rep、截图、Trace、事件流、HTML 报告和诊断包默认保存在本机。它们可能包含页面正文、输入内容、URL、网络请求、桌面截图、窗口标题、Agent Prompt 和模型元数据。

下载或分享前应逐项检查。密码字段会尽量脱敏，但不能把自动脱敏视为绝对安全保证。

## 数据管理

macOS 客户端默认数据目录为：

```text
~/Library/Application Support/UIWarden/data
```

重新安装通常保留数据。删除会话、评测结果或整个数据目录是不可逆操作，操作前先停止相关任务并按[部署指南](DEPLOYMENT.md)备份。

## 问题排查顺序

1. 记录会话 ID、执行底座和模型。
2. 查看活动步骤，确认是否真正产生观察和原子动作。
3. 检查首张/末张截图、Browser Rep 或 Native Rep。
4. 区分底座错误、模型错误、Runtime/Provider 错误、权限错误和断言错误。
5. 导出单次诊断包，并在分享前移除敏感数据。

安装、系统权限和打包问题见[桌面客户端指南](CLIENT_GUIDE.md)。
